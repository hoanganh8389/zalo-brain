## 0. Kết luận một câu

**Vault = `core/skills`** (thư viện Skill cũ được nâng cấp — chủ, 0.133). Nhưng qua 0.121 → 0.145, **mã server** của Vault, Journal, Brain map, Twin Sheet bị đặt dần vào `core/kg-hub`, còn **màn hình** đặt vào TwinChat. Vì vậy 0.148 không tạo `core/vault/` mới: nó **trả Journal + Vault server về `core/skills`** (nơi Journal từng ở trước WP-12) và đưa các màn Sổ cái / Brain map / Twin Sheet về trang 📚 Kho tri thức (`core/skills/app`).
